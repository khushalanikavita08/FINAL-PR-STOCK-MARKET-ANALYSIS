## 🚀 Overview
This project analyzes **Reliance Industries (RELIANCE.NS)** stock data from 2020–2024 using Python.  
It fetches **live data** via `yfinance`, performs **feature engineering** (moving averages, returns, volatility), and generates **visualizations** for better understanding of stock behavior.  

The goal is to make stock analysis **clear, interactive, and visually appealing** — perfect for reports, presentations, or personal learning.



## ⚡ Run Live
```bash
python stock_analysis.py
➡️ Instantly downloads the latest Reliance stock data and updates all charts.
No static numbers — every run is fresh, every chart is live.

🔑 Key Features
📈 Moving Averages – SMA (20, 50) & EMA (20) for trend detection

📊 Daily Returns – Percentage change in closing price

📉 Volatility – Rolling 20‑day standard deviation

📂 Trading Volume – Bar chart visualization

🔥 Correlation Heatmap – Relationship between price, volume & indicators

🎨 Attractive Visuals – Saved as PNG files for reports/presentations

⚡ Live Data Pull – Always up‑to‑date with Yahoo Finance
